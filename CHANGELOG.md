# Changelog

All notable changes to ReMTR will be documented here.

## 0.1.0

- Initial Apple Silicon IPv4 ICMP route monitor.
- Per-hop loss, latency, jitter, history, and path-change statistics.
- Colorful terminal table, selected-hop sparkline, and route graph.
- Snapshot mode, macOS arm64 packaging, signing, and notarization workflow.
